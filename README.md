# HomogmosLab Studios — v0.4

Sitio editorial y visual para **HomogmosLab Studios**, construido con **Astro** y pensado para publicarse desde **GitHub** en **Cloudflare Pages**.

## Identidad

- Paleta basada en el logo de Instagram: azul noche, verde esmeralda, carbón y marfil.
- Slogan oficial: **Exploring life. One thought at a time.**
- Filosofía editorial: **One investigation. Many ways to tell the story.**

## Incluye

- Home visual y editorial
- Stories
- Página individual de historia
- Journal
- Field Notes
- Audio
- Films
- Studio
- Contact

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```

## Publicación en Cloudflare Pages

- **Build command:** `npm run build`
- **Build output directory:** `dist`

## Notas

- El formulario de contacto es de demostración y debe conectarse a un correo o servicio real.
- Los contenidos son ejemplos conceptuales coherentes con la visión del proyecto; no se presentan como publicaciones ya terminadas.

## Visual assets

Las imágenes de `public/visuals/` son recortes de composiciones visuales conceptuales generadas para el estudio. Son ilustraciones de atmósfera, **no fotografías documentales ni reconstrucciones científicas verificadas**.
